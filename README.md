# Descrição do Projeto
Este projeto é uma recriação simplificada da interface do YouTube, desenvolvida com HTML e CSS puro, com foco em layout responsivo utilizando Flexbox e boas práticas de estilização.

# O que a página possui

* Cabeçalho fixo com menu, barra de pesquisa e ícones de perfil.

* Seção principal com vídeo em destaque utilizando iframe, botões de interação (curtir, compartilhar, etc.) e informações do vídeo.

* Barra lateral com lista de vídeos recomendados, todos funcionando para navegação entre links.

* Layout adaptável, ajustando-se automaticamente para diferentes tamanhos de tela, incluindo dispositivos móveis, tablets e desktops.

# 📱 Responsividade
O site foi projetado para ser totalmente responsivo, mantendo usabilidade e estética em qualquer dispositivo.
A responsividade foi implementada com Flexbox e Media Queries, permitindo que elementos como o vídeo principal, barra lateral e botões se reorganizem automaticamente para oferecer a melhor experiência possível ao usuário.
